# Orb releases

[Download Orb 0.3.0](https://jonkthomas.github.io/substrate-orb-releases/).

Requires an Apple Silicon Mac running macOS 15.0 or later.

1. Download and open the DMG.
2. Drag Substrate Orb to Applications.
3. Open Substrate Orb and follow setup to sign in.

Orb checks for updates using the signed [appcast](https://jonkthomas.github.io/substrate-orb-releases/appcast.xml).
